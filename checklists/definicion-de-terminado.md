# Definición de terminado

- [ ] Todos los criterios de aceptación cumplidos y probados.
- [ ] Suite de pruebas completa en verde (en todos los motores o entornos que use el proyecto).
- [ ] Revisión de código sin hallazgos bloqueantes ni importantes abiertos.
- [ ] Control de calidad: PASA o CON OBSERVACIONES aceptadas por el PO.
- [ ] Documentación actualizada si cambió algo visible, de configuración o de despliegue.
- [ ] Historia y estado del sprint actualizados.
- [ ] Cambio en una rama o PR, listo para el proceso de publicación del proyecto.
